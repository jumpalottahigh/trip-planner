# Future features

Features discussed and deferred until after the first working version of the vacation planner. These are future steps, not implemented functionality.

## 1. Choose event colors

- Let the user choose an event's color instead of relying only on automatic colors.
- Keep the existing app's palette and visual style.

## 2. Event notes and links

- Add notes and links to an event for extra itinerary details.
- Keep the day grid focused on the event name and time range.

## 3. Multiple trips with pill navigation

- Support multiple named trips instead of only one saved trip.
- Switch between trips using pills in the header area where the trip start/end date controls currently sit.
- Keep each trip's dates and events separate.

The exact editing and storage behavior for these additions should be agreed before implementation. The numbering groups the features; it does not establish an implementation order.

## Other possibilities, not committed next steps

The initial plan also left overnight/multiday events, finer-than-hour scheduling, spreadsheet import/export, and cloud sync/accounts/backend support outside version 1. These were not selected as the next features and need a separate scope discussion if wanted.
